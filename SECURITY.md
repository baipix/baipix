# Security policy

Baipix runs entirely in the browser: drawings stay on your computer and are never uploaded. It still opens files made by others (`.baipix`, images, palettes), so a bug there could be a security issue.

## Reporting a vulnerability

Please don't open a public issue. Report it privately instead: [open a security advisory](https://github.com/baipix/baipix/security/advisories/new) (under the Security tab, "Report a vulnerability"). Only the maintainers see it.

Say what happens and how to reproduce it; a file that triggers it helps a lot. You'll get an answer within a week, and credit in the changelog once it's fixed, if you want it.

## Supported versions

Only the latest version, the one at [baipix.app](https://baipix.app), gets fixes.
